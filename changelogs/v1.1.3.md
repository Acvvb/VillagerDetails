## English

### 🚀 Version Overview
v1.1.3 adds the **Piston Move Control** rule (a single block list controlling piston push, sticky-piston pull and being carried along by honey / slime blocks) and fixes several settings-screen problems: the rule description overlapping the config area, the list detail pages ignoring the mouse wheel, and the scrollbar that could not be dragged by its thumb. Applies to **26.2 / 26.3**.

### ✨ New Features

#### 🎮 Game Rules
- Added **Piston Move Control** (`CustomPistonPushBlock`): configure any block once and control three behaviours at the same time — whether a piston can push it, whether a sticky piston can pull it back, and whether honey / slime blocks stick to it and carry it along.
  - `true` makes a block that vanilla cannot move (obsidian, crying obsidian, respawn anchor, blocks with block entities …) behave **exactly like stone**: it can be pushed, pulled back, and carried away by sticky blocks.
  - `false` makes a block that vanilla can move **immovable**: it cannot be pushed, cannot be pulled back and does not stick.
  - A value equal to vanilla is not stored at all (the entry is deleted automatically), and blocks not on the list keep vanilla behaviour.
  - The edit is applied on both sides (the client keeps a synced mirror), so single-player prediction matches the server.

#### 🖥️ Settings Screen (Client)
- Rule detail pages: the description is measured with its real wrapped line count, and the config area is pushed down to leave a fixed gap below it — long descriptions no longer run into the config list.
- List detail pages now respond to the **mouse wheel** (scrolling 3 rows per notch with the same smooth animation as the main config screen).
- The scrollbar now supports **dragging by its thumb**: the thumb follows the pointer 1:1, clicking the track pages once, overshooting an end absorbs the surplus (dragging back reacts immediately), and a screen rebuild no longer interrupts a drag in progress.

### 🐛 Bug Fixes
- Fixed the rule description overlapping the config area on the settings detail pages.
- Fixed the list detail pages ignoring the mouse wheel (only the scrollbar thumb worked, and only via dragging).
- Fixed the scrollbar being impossible to drag by its thumb (the left mouse button is reported differently since 26.3; the button check is now version-agnostic).
- Fixed the scrollbar getting stuck at an end after overshooting it (no reaction when dragging back).
- Fixed a drag being dropped halfway through when the screen rebuilt itself (the drag state now lives on the page component instead of the recreated scrollbar widget).

## 中文

### 🚀 版本定位
v1.1.3 新增**活塞搬运控制**规则（用一份方块名单同时控制活塞推动、粘性活塞黏回、以及被蜂蜜块 / 史莱姆块黏住带走），并修复了设置界面的若干问题：规则描述压住配置区、列表详情页不响应该鼠标滚轮、滚动条无法按住滑块拖动。适用于 **26.2 / 26.3**。

### ✨ 新增功能

#### 🎮 游戏规则类
- 新增**活塞搬运控制**（`CustomPistonPushBlock`）：一个方块只配一次，就能同时控制三件事 —— 活塞能不能推动它、粘性活塞能不能把它黏回来、蜂蜜块 / 史莱姆块能不能把它黏住并带走。
  - 配成 `true`：原版搬不动的方块（黑曜石、哭泣的黑曜石、重生锚、带方块实体的方块……）会变得**和石头完全一样** —— 推得动、黏得回来、也会被粘性方块带走。
  - 配成 `false`：原版能搬动的方块变得**搬不动** —— 推不动、黏不回来、也黏不住。
  - 设置成和原版一致时不会落库（条目自动删除），不在名单里的方块完全走原版。
  - 两端同时生效（客户端保留一份同步镜像），单人游戏里的预测与服务端一致。

#### 🖥️ 设置界面（客户端）
- 规则详情页：说明文字按真实换行行数测量，配置区整体下移、在描述下方留出固定间距 —— 描述再长也不会压到配置列表上。
- 列表详情页支持**鼠标滚轮**（一格 3 行，和主配置界面同一套平滑动画）。
- 滚动条支持**按住滑块拖动**：滑块 1:1 跟手、点轨道翻一页、拖过端点后多余位移被吸收（往回拖立即有反应）、界面刷新不再打断正在进行的拖动。

### 🐛 问题修复
- 修复设置详情页规则描述与配置区重叠的问题。
- 修复列表详情页不响应鼠标滚轮的问题（此前只有拖动滚动条滑块有用）。
- 修复滚动条无法按住滑块拖动的问题（26.3 起鼠标左键的编号变了，改为走版本自适应的按钮判定）。
- 修复滚动条拖过端点后卡在端点、往回拖没有反应的问题（拖动死区）。
- 修复界面重建时正在进行的拖动被打断的问题（抓取状态改挂在页面组件上，不再依赖会被重建的滚动条控件）。
